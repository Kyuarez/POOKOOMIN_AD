아나모픽 광고 영상 작업물 입니다.
"뿌꾸민 AR 프로젝트를 아나모픽 광고로 촬영하자"라는 컨셉으로 작업을 했습니다.

"뿌꾸가 꽃을 줍는 임무를 받고, 열심히 달려가서 꽃을 줍는데 성공한다.
그러자, 갑자기 주인님이 호출 요청을 하고 급하게 달려간다."

* **프로젝트 이름**: Pookoomin_AD 🏠
* **프로젝트 지속기간**: 2025.07.07 ~ 2025.07.17
* **개발 엔진 및 기술**: Unity(Timeline), C#, Blender 3D, Mad Mapper
* **팀 멤버**: 팀 "뿌꾸의 산책" (김민정, 정보연, 한태규)
